# GMOD-Script-Cheat-Pack
----
## This set of Lua scripts is 4 cheats for the game Garry's mod.
---
## This script pack contains the following cheats:

  **WallHack**

  **AimBot**
   
  **AutoWall**
  
  **AutoBunnyHop** 


_p.s I'll tell you right away that I didn't make a cheat menu, so all the cheats are enabled by default. If you want to remove any of the cheats, just delete it from the folders that I'll indicate below._

---
# How to install scripts for use?


### 1.open steam


### 2.Open the Garry's mod page and then click on the gear icon (it's to the left of the "PLAY" button).


### 3.After clicking on the gear, click "Properties," then click "View installed files," then click "Browse."


### 4.Go to **garrysmod/lua/autorun/client** and move the following files there
Aim.lua

Autobhop.lua

WallHack.lua

start_msg.lua

AutoWall(CLIENT).lua

# then go to the path **garrysmod/lua/autorun/server/**



## In the folder along the path **then go to the path garrysmod/lua/autorun/server/** move the following file:


AutoWall(SERVER).lua


---

### Next, go to the game on any local server and have fun
